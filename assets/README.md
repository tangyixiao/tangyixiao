## Generation prompt

Use case: illustration-story. Asset type: small original GitHub profile side illustration, transparent background, tall portrait silhouette. Create an exquisitely drawn modest little still life of a well-used open study notebook and an open compact laptop, a sharpened mechanical pencil resting across the notebook, two thin books tucked below, and a tiny folded page tab. The laptop screen shows three very sparse lines of code as non-readable short ink marks and one small branching tree diagram. Notebook has a few natural pencil calculation marks and a loose small curve, no readable text or equations. Quiet ordinary student and open-source developer feeling, human and slightly imperfect. Fine graphite pencil and dry watercolor, like a real sketchbook drawing scanned and carefully cut out. Mostly warm charcoal line work, paper white, muted slate blue and restrained sage green, one small ochre paper tab. Asymmetric natural composition with notebook bottom left and laptop upper right, slight overhead perspective. Strong enough shapes to remain recognizable at 128px wide. Organic, tactile, understated. No person, no invented mascot, no cat, no fantasy, no glossy 3D, no gradient background, no neon, no orbit, no celestial motifs, no floating UI panels, no UI dashboard, no badges, no logos, no large title, no handwriting slogan, no text, no border, no drop shadow beyond the natural paper edges. Standalone isolated drawing with generous truly transparent margins. Aim for the visual personality of a careful hand sketch, not a stock productivity illustration.

## Generated contribution and article cards

The `generated/` images use tangyixiao's own public data. They are generated by the repository workflow, not copied from the upstream example galleries. The two calendar types are both retained at the user's request. The 3D landscape has matching light/dark palettes. Other generated SVGs include their own light/dark styling.

The calendars use native renderers in `scripts/profile-cards/`, with projection references from [lowlighter/metrics](https://github.com/lowlighter/metrics) and a logarithmic height formula adapted from [github-profile-3d-contrib](https://github.com/yoshi389111/github-profile-3d-contrib). Their MIT license texts are retained in `licenses/`. These sources are credited references; the workflow no longer runs their rendering Actions. Data sources, limits, workflow permissions, and the required bot/user `Co-authored-by` trailer are documented in `docs/profile-cards.md`.

Lower project cards are generated from explicitly selected public repository metadata and reviewed bilingual descriptions. Language contribution charts show concrete language names without an `other` bucket. The expanded language chart uses primary repository languages weighted by public commit contributions, separately from the byte-based overview language card.

The dynamic project cards use the same GitHub Stats Extended instance as the overview. Their release/last-commit badges use Shields. The recent-activity graph uses the official Workers host of [github-readme-activity-graph](https://github.com/Ashutosh00710/github-readme-activity-graph). No third-party examples, manual competition statistics, or credentials are embedded in these cards.
